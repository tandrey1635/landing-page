# Сайт «New Automation Tool for Your»
Первый проект. Адаптивный веб-сайт из двух страниц на чистом HTML5/SASS с семантической версткой.

## 🛠 Технологический стек

### Frontend
- **HTML5** — семантическая верстка, БЭМ-методология
- **SASS/SCSS** — модульная структура, сброс стилей, медиа-запросы

## 🎯 Ключевые функции

### UX/UI элементы
- Навигация между главной страницей и контактами
- Карточки услуг с иконками, текстом и ссылками "Learn more"
- Портфолио проектов с адаптивными изображениями
- Детальная контактная информация с иконками
- Интерактивная карта


## 🔧 Технические особенности

### Адаптивность
- Адаптивный дизайн
- Медиа-запросы
- Кросс-браузерная совместимость


**Проект демонстрирует чистую адаптивную верстку без использования CSS-фреймворков и уверенное владение современными подходами к веб-разработке.**
