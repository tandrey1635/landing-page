# Лендинг "New Automation Tool for Your" с адаптивным дизайном
Веб-сайт из двух страниц с современным адаптивным дизайном.

## 🛠 Технологический стек

### Frontend
- **HTML5** - семантическая верстка, БЭМ-методология
- **SASS/SCSS** - препроцессор для стилей, модульная структура


## 🎯 Ключевые функции

### Пользовательский интерфейс
- Портфолио проектов с адаптивными изображениями
- Детальная контактная информация с иконками

### Интерактивные элементы
- Интерактивная карта

### UX/UI компоненты
- **Навигация** - переключатель между главной страницей и контактами
- **Карточки услуг** - с иконками, текстом и ссылками "Learn more"

## 🔧 Технические особенности

### Адаптивность
- Адаптивный дизайн
- Медиа-запросы
- Кросс-браузерная совместимость


**Проект демонстрирует чистую адаптивную верстку без использования CSS-фреймворков и уверенное владение современными подходами к веб-разработке.**
